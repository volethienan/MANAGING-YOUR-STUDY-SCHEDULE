# Study Planner Mobile UI

File thiết kế chính:

- `study-planner-mobile-ui.svg`

Nội dung:

- UI kit nhỏ: màu sắc, typography, button, card, input, tag, bottom navigation, icon style.
- 19 màn hình app mobile Study Planner theo frame Android `390x844`.
- Có bổ sung màn hình `Thêm lịch / sự kiện` và `Xác nhận thông tin OCR` để prototype flow đầy đủ hơn.
- Màn hình prototype flow cho 3 luồng chính:
  - Onboarding -> Dashboard -> Thêm lịch -> Chụp ảnh lịch -> Xác nhận thông tin -> Lưu lịch.
  - Dashboard -> To-Do -> Thêm task -> Pomodoro.
  - Dashboard -> Thống kê.

Cách xem:

- Mở trực tiếp file SVG bằng trình duyệt.
- Import file SVG vào Figma hoặc Pencil để xem/chỉnh từng group/layer.

Ghi chú:

- MCP Pencil trong phiên này chưa kết nối được với editor đang chạy, nên thiết kế được xuất dưới dạng vector SVG để vẫn xem và import được.
- Các nhóm trong SVG được đặt theo tên màn hình và component để dễ tìm trong Figma/Pencil.
